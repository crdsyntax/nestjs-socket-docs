# UI Agent

## Responsibilities
- Modify `packages/ui`.
- React components in `src/components/`.
- Custom hooks in `src/hooks/`.
- API and Socket services in `src/services/`.
- Styling with TailwindCSS.

## Workflow
1. Review `src/types.ts` for data consistency.
2. Modify UI components maintaining a modern aesthetic.
3. Test changes with `npm run dev` in the UI package.
